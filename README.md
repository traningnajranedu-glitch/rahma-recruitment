# نظام الرحمة المحاسبي

واجهة عربية لإدارة محاسبة الاستقدام ونقل الخدمات، مبنية على Next.js وقاعدة PostgreSQL في Supabase.

## التشغيل
1. تثبيت الحزم: `pnpm install --frozen-lockfile`
2. نسخ `.env.example` إلى `.env.local` وتعبئة SUPABASE_URL وSUPABASE_PUBLISHABLE_KEY. لا تستخدم service_role في الواجهة.
3. تنفيذ `supabase/schema.sql` في مشروع Supabase جديد مخصص للشركة.
4. إنشاء حساب المدير عبر Authentication > Users في Supabase، ثم إضافة user_id إلى app_members بدور admin عبر SQL Editor.
5. تشغيل `pnpm dev` أو `pnpm build`.

## النشر
ارفع المستودع الخاص إلى GitHub، ثم Import Project في Vercel. أضف متغيري البيئة من الخطوة 2 لكل بيئة مطلوبة، ثم Deploy.

## الصلاحيات
الدخول عبر Supabase Auth. RLS يمنع المستخدمين غير المسجلين في app_members من قراءة البيانات. admin وaccountant يسجلان العمليات؛ viewer للقراءة. لا يمكن للمستخدم منح نفسه صلاحية. لا تُعدل أو تُحذف العمليات المرحلة؛ التصحيح بقيود عكسية.

## الأمان والمحاسبة
المبالغ بالسنت/الهللة الصحيحة. حواجز قاعدة البيانات تتحقق من التوازن والسداد والمخزون. الجلسات في كوكيز HttpOnly. لا يحوي المستودع كلمات مرور أو مفاتيح سرية.

الفواتير محاسبية داخلية، والتكامل مع الفوترة الإلكترونية غير مفعل. المخزون سجل كمي مستقل.
